# Типограф: висячие предлоги

**Русский** · [English](README.en.md)

Плагин WordPress, который убирает висячие предлоги и союзы в русских текстах: короткие слова, частицы, тире и единицы измерения не отрываются от соседнего слова.

Висячий предлог — короткое слово в конце строки, оторванное от следующего: «в», «на», «не», «и». Типограф ставит между ними неразрывный пробел, и браузер переносит их на новую строку вместе.

## Что делает

- **Короткие слова.** Предлоги, союзы и короткие местоимения держатся за следующее слово: «с&nbsp;вами», «на&nbsp;сайт», «не&nbsp;всегда». Список слов можно поменять в настройках.
- **Частицы.** Же, ли, бы держатся за предыдущее слово: «он&nbsp;же», «был&nbsp;ли».
- **Тире** не переносится в начало строки: «Москва&nbsp;— столица».
- **Числа и сокращения:** «10&nbsp;м», «5&nbsp;шт», «№&nbsp;5», «г.&nbsp;Москва».

Каждое правило включается и выключается отдельно: **Настройки → Типограф**.

## Как работает

- Обрабатывает готовую страницу целиком при выдаче: тексты записей, заголовки, меню, поля, подписи в шаблонах темы.
- Трогает только видимый текст. Теги, атрибуты, ссылки, скрипты, стили, `<head>`, `<pre>` и `<code>` остаются как были.
- Тексты в базе не меняются: выключили плагин — всё как раньше.
- С кешем страниц (WP Super Cache, WP Rocket, LiteSpeed) обработка идёт один раз, когда страница попадает в кеш. После включения, выключения и изменения настроек кеш сбрасывается сам.

## Требования

- WordPress 6.5 или новее
- PHP 7.4 или новее

## Установка

1. Скачайте архив репозитория и распакуйте папку `tipograf` в `wp-content/plugins/`.
2. Включите плагин в разделе **Плагины**.
3. **Настройки → Типограф:** выберите правила и при желании поправьте список коротких слов.

## Подгрузка через AJAX

Плагин обрабатывает обычные страницы. Если тема подгружает HTML через `admin-ajax.php` (например, кнопка «Показать ещё»), перечислите эти действия в фильтре:

```php
add_filter( 'tipograf_ajax_actions', function ( $actions ) {
	$actions[] = 'loadmore';
	return $actions;
} );
```
